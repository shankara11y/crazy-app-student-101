## 🚀 About the Project

Secret Agent Hacker Terminal is an interactive web application created using HTML, CSS, JavaScript, and AI-assisted coding. It features a retro hacker-style interface with neon green colors, animated effects, fake system messages, and a secret cipher mini-game.

## 🎮 How to Use

1. Open the live website.

## 🤖 AI-Assisted Debugging

As part of the AI Coding Lab assignment, I intentionally changed a JavaScript function name to introduce a bug. This caused an error when the program called the original function name. I used an AI coding assistant to identify the mismatch and correct the error.

## 🏀 Code Explanation Analogy

The animation loop is like a DJ at a party, continuously keeping the lights and effects moving to make the hacker terminal look alive and exciting.

## 🧪 Testing

Three `console.assert()` tests were added to demonstrate testing for:

1. Normal input
2. Zero or empty input
3. Negative input

These tests help verify that the relevant JavaScript function produces the expected results for different inputs.

## 🛠️ Technologies Used

- **HTML** — Structures the web page.
- **CSS** — Adds styling, neon colors, and animations.
- **JavaScript** — Handles interactions, animations, and testing.
- **AI Coding Assistant** — Helps generate, explain, debug, and test code.
- **GitHub Pages** — Hosts the application online.
